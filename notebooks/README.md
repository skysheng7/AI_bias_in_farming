# Notebooks

This directory contains Jupyter notebooks for exploratory data analysis and visualization of final results in the AI representation bias in farming project.

## Notebook Descriptions

- `megadata_plot_generation.ipynb`: Generation and exploration of metadata visualizations and statistical plots.
- `image_clustering.ipynb`: Interactive analysis of image clustering to identify patterns in AI-generated farming imagery.

## Usage

These notebooks are using functions built in `AI_representation_bias_in_farming` python package under `src`, and are meant for interactive exploration and analysis. These notebooks uses the results generated after running `scripts`.
